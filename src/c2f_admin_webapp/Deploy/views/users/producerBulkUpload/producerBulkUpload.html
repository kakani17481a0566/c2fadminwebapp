Instructions to be followed for Upload File Format
Download demo csv file, enter data and upload along with 1st row(Header row) (Donot remove Header row)
1. The format used to upload a file is .csv (filename.csv)
2. Spaces should be avoided
3. Give these values for the following inputs :
i. Language - EN for English, TU for Telugu
ii. Status - ACTIVE / INACTIVE
iii. Producer Type - FARMER / RBK / OTHERCLUSTER
iv. Bill Collection - INSTANT / DAILY / WEEKLY / BIWEEKLY / MONTHLY
v. Bill Type - PREPAID / POSTPAID
vi. Collection Mode - CASH / ONLINE
vii. Location Type - MapMyIndia
4. Add data in this following sequence :-
First Name,Middle Name,Last Name,Mob No,Email,Address1,Address2,City,Zipcode,State,Language,Status,Producer Type,Bill Collection,Bill Type,Collection Mode,Village,Location Type,Location Info,Cluster Name
Example : Hitha,R,S,5555512365,hitha24@gmail.com,Mandya,Mandya,Mandya,571424,KA,EN,ACTIVE,FARMER,MONTHLY,PREPAID,CASH,Mandya,MapMyIndia, ,Bangalore
