Instructions to be followed for Upload File Format


  • Download demo csv file, enter data and upload along with 1st row(Header row) (Donot remove Header row)
  • The format used to upload a file here is .csv (filename.csv)
  • The entered data should be correct and spaces should be avoided
  • Customer Mobile Number,Customer Name and Product Name and Cluster Name should be correct
  • Add data in this following sequence :-

  • Example : 9876543210,Nuzvid,Raagi,5Kg,500,2022-08-01,2022-08-31,RBK

  • Product Quantity should be only Product Quantity Unit , example : Kg , Lts
